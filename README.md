# Замер скорости скачивания

Скрипт выполняет 10 последовательных GET-запросов по указанному URL. Каждый следующий запрос начинается после чтения всего тела предыдущего ответа.

## Запуск

Нужен Python 3.8 или новее. Дополнительные зависимости не требуются.

```bash
git clone https://github.com/D1sney/download-speed-test.git
cd download-speed-test
python3 speed_test.py "https://example.org/"
```

Для замера на большом объёме данных подставьте прямую ссылку на крупный файл, например изображение или архив.

## Результат

- Среднее время запроса в секундах — сумма длительностей 10 запросов, делённая на 10. Длительность измеряется от начала запроса до завершения чтения ответа.
- Общий объём скачанных данных в байтах — сумма размеров тел ответов.
- Скорость скачивания в **Мбит/с** (1 Мбит = 1 000 000 бит) — общий объём в байтах, умноженный на 8 и делённый на суммарное время в секундах и на 1 000 000.

Замер показывает скорость скачивания с выбранного сервера. При ошибке запроса скрипт выводит сообщение в stderr и завершается с кодом 1.
